# dashboards/ — Phase 5 (not yet built)

Holds the cost results in three forms from one source (the pipeline's cost query):
- `*.csv` — Power-BI-ready cost data (cost by service, cost over time, unit cost, cost per iteration).
- `*.png` — committed matplotlib figures (reproducible-from-code), generated by `scripts/make_figures.py`.
- Power BI exports — the polished/interactive dashboards for the paper + video (built manually from the CSVs).
