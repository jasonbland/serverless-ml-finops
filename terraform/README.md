# terraform/ — infrastructure as code

The entire serverless stack, `apply`/`destroy`-able and tagged `Project=capstone`:

- `main.tf` — Lambda (`hof-inference`), API Gateway HTTP API (`POST /predict`), versioned S3 model bucket, least-privilege IAM execution role, CloudWatch log group.
- `observability.tf` — CloudWatch dashboard (`capstone-mlfinops`) + saved Logs Insights queries.
- `github_oidc.tf` — GitHub OIDC provider + a scoped, read-only CI role (no stored keys).
- `variables.tf` / `outputs.tf` — inputs and outputs (tables below).

State stays local and **gitignored** (`*.tfstate`). See [`../ARCHITECTURE.md`](../ARCHITECTURE.md) for the design rationale.
